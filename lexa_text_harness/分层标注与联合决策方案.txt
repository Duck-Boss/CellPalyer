一、核心选择

保留用户的两层标注：axis 说明涉及哪些基因活动，state 说明该轴的一种具体表达模式。增加运行时的“变化卡”，明确从当前状态到候选状态究竟改变什么。决策采用全局计划、逐轴提案、联合检查；所有 32 轴都可进入候选，不沿用最多 3 轴的硬限制，也不要求每次都修改全部轴。

LEXA 原文 Sec.3.5 和 App.B.1/B.2 已有轴与状态的分层解释。新工作的价值应通过语言条件执行、真实扰动预测、组合一致性或效率的实验体现，不能把层级标注本身作为新贡献。

坚持纯文字接口：DeepSeek 读取文字和 JSON，数值张量、枚举候选、概率约束和解码留在本地工具；不需要新增 LLM token、微调 LLM 或训练可学习编辑器。

当前模型是 sciPlex2 A549、2000 个训练选择基因、32 轴×16 状态的 pilot，训练 5285 细胞，固定 24h。它不是论文 atlas 权重，轴编号和功能名不能跨模型直接迁移。

此前已揭盲的 5µM 数据，每药 4 孔等权的群体主导 code 更换轴数为 BMS31、Dex29、Nutlin31、SAHA32（共32轴）。这说明不能未经验证就把真实响应限制成少数轴；这些计数也不代表独立生物功能数或显著改变的轴数。

本轮 train-only 诊断：5285 训练细胞、其中910零剂量细胞、107个 drug-dose-plate-replicate 组，496轴对。按轴内中心化效应的 RMS / max(训练基因SD,0.05) 选 top50 基因，轴对 Jaccard 中位数0，仅4对>0.1；mask余弦中位数0.0396，55对>0.3。code的调整互信息AMI中位数全训练0.2559、零剂量0.1566；按条件组内独立置换各轴3次后，实际AMI减置换均值的中位数0.1212。这是描述性关联，不是显著性检验、条件互信息或因果耦合。主要效应基因分开，不保证 code 统计独立。

三、标注设计

1. 轴卡：功能范围，不预先规定方向

axis_id、checkpoint/effects hash、候选功能集合、支持等级 supported/mixed/unknown；高责任mask基因；真正随该轴state变化的基因；富集/基因集证据；训练细胞背景及状态占用；相关轴与已知局限。

同时看 mask 和实际状态效应动态范围，避免把“被分配到该轴但变化很小”的基因当作主要驱动。一个轴可以对应多个功能，也允许暂时没有可靠功能名。相关轴可作软提示，不把训练共现当作确定调控关系。

富集背景使用当前2000个建模基因中成功映射到所用注释数据库的集合，保留完整ID映射、缺失率、数据库版本和多重检验方法。不能直接把论文10310基因背景和top300/top500阈值搬到本pilot。参考 GO 官方背景集说明：https://www.geneontology.org/docs/go-enrichment-analysis/

2. 状态卡：保留正负与混合模式

固定参考为本轴16状态的均匀平均贡献，保存每个基因有符号贡献、正向/负向功能证据、最能区分相邻候选的基因、训练占用率及支持背景。另在运行时显示相对当前对照占用分布的效应，不能把两种参考混用。状态ID是类别，C15不天然比C2强。

当前轴19的真实已有标签可作为格式例子：
- A19_C4：FDXR/CDKN1A/TP53I3/MDM2 等标志的模型贡献较高。
- A19_C6：上述多项标志贡献较低。
- A19_C0：FDXR/CDKN1A较高、TP53I3较低的混合模式。
轴19可暂用“FDXR/CDKN1A/TP53I3/MDM2相关表达程序”作为基因证据名；“p53相关”属于有待数据库/人工复核的功能解释，不把模型贡献等同于实测信号活性。已有 DeepSeek 标签通过了格式/基因引用检查，未完成系统生物学审核。

3. 按需变化卡

给定源状态s、候选状态t：逐基因差值为 u[a,t,g]-u[a,s,g]；若评价整个群体候选占用q，则差值为 sum_s (q[a,s]-p0[a,s])*u[a,s,g]。
输出准确的上/下调基因、预设功能分数变化、保持项影响、来源状态可用比例、训练支持和不确定性。功能分数是所定义表达评分的变化，不是直接测得的信号通路活性。数值依据来自完整2000基因，文字只作摘要。

无需永久生成32×16×15份长文字；缓存两层静态卡，再按实际候选即时计算变化卡。每个事实附 evidence_ref，语言改写不能生成新生物学证据。

四、预测对象与 agent 流程

输入：匹配对照的32×16占用p0，药物/刺激描述、剂量、时间、细胞背景，以及在预测时合法可用的训练响应示例。当前数据固定24h，尚不能验证时间泛化。

输出：目标群体每轴16状态占用 q[a,s]>=0，sum_s q[a,s]=1，加证据引用、不确定项和拒绝理由。每个真实细胞仍是32个离散code；群体输出应保留每轴多种状态的比例。q不是同一细胞前后配对，不识别真实单细胞转移。

推荐顺序：
A. 训练响应检索建立全局先验。对训练well匹配各自control，保存drug/dose/time/context、表达Δ和code占用Δ。先实现同药最近剂量的code占用基线；将训练参考的Δp加到当前p0后，需用明确的非负/和为一约束得到可行分布，记录约束造成的调整。只在训练/验证数据上选择插值、平滑或幅度校准，不用5µM答案设定幅度。
B. DeepSeek总览32张短轴卡和先验，形成共享的变化假设、需要保留的项目和不确定项。药物机制文字本身不足以确定定量剂量效应。未见药物只能用支持较弱的近邻/机制证据，应分别评测。
C. 分批检查全部32轴，按需要展开状态卡。每轴给维持原状以及少量候选分布/方向提案和证据；可先采用2–4个候选，但数量只是开发参数。调用按若干轴合批，不必创建32个互不共享信息的agent。
D. 本地工具计算候选的完整基因效应，约束或校准比例。没有训练响应或明确功能目标时，工具不能凭空判断哪个候选更接近药物真实效应。对纯功能编辑，可用用户给定目标与保持项定义代价；对药物预测，评价依据只能来自合法训练先验、机制证据和模型一致性。
E. 全局协调器合并所有提案，检查共享基因叠加/抵消、整体幅度、保持项、与训练联合code组合的兼容程度，再只重审有冲突的轴。目标和保持项可能冲突，应报告取舍而非声称全部满足。以软变化代价鼓励少改，避免最多3轴硬限制；也避免为追逐已有29–32轴现象强制多改。
F. 冻结预测和trace，再用独立真实扰动数据评分。全局一致性反馈不是药效准确率，LLM自述置信度不是校准概率。

第一版优先做“检索先验＋语言修正”，并保留“机制文字从零预测”作为单独路线。前者可以让32轴都有合理起点，语言重点处理候选差异和冲突；若未超过同信息的纯检索基线，则尚无语言增益证据。

五、解码与联合分布边界

本次冻结加法解码器下：
  delta_hat[g] = sum_a sum_s (q[a,s]-p0[a,s])*u[a,s,g]
因此只凭轴边际占用就能准确计算模型群体均值变化。报告预测时可用 observed_control_mean + delta_hat；应与既有直接decoder绝对重建区分，主评测仍比较变化量。

q的各轴边际不能唯一确定全细胞32轴联合分布。独立抽样各轴能得到数学有效组合，但可能不在真实细胞分布内。第一阶段只承诺群体均值和边际占用预测；若要生成单细胞，应另加入完整code向量重采样/有条件联合生成，检验相关结构和真实群体分布。近邻Hamming或训练共现只提供诊断，不能证明新细胞真实；不能硬性禁止一切训练未见组合。

六、验证顺序和公平比较

先做训练/验证数据上的表示与编辑容量诊断：比较3轴、更多轴、完整占用分布的目标拟合能力。这一步允许使用真实响应作为拟合目标，仅诊断可表达程度，不能作为预测成绩或严格上界。

再固定信息、编辑空间、API/token/数值评价预算，分步比较：
1) 平铺卡 vs 轴—状态分层卡；其余完全一致。
2) 分层卡下逐轴独立拼接 vs 提案后全局协调。
3) 单条source→target操作 vs 多状态占用编辑；先容量诊断，再预测比较。
4) 纯检索/简单剂量插值 vs 检索＋LLM修正。
5) 正确文字、同轴打乱文字、去文字但保留同样数值证据，检验语义增益。

编辑空间变化与层级标注变化分别比较，避免把更宽搜索空间归因于语言。多轮agent与相同预算的独立提案也需比较，避免把尝试次数归因于反馈。

主要真实结果：每孔相对匹配control的2000基因ΔRMSE、ΔPearson、幅度比、预先规定基因集方向；code层报告各轴TV/JSD预测误差、占用Δ误差、主导code命中等。基因层为主要结果，code层解释来源；主导code相同也可能有明显比例变化。轴改变阈值在训练/验证确定，不能把任何微小差异当显著。

孔内汇总、药物内孔等权、再药物等权；不把细胞当独立生物重复。全部失败和低样本排除保留。多seed/对照bootstrap可作测量稳定性诊断，不替代独立生物重复。

原5µM已经揭盲，后续调设计将它视为开发集。正式评价需新未触碰数据/新隔离fold；若改heldout条件，HVG/scaffold/LEXA/labels都必须按新训练划分重建，不能复用见过新测试的旧权重。药物预测和自然语言功能指令执行属于不同目标，分别报告。
