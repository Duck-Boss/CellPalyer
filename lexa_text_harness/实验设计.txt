LEXA × DeepSeek：以纯文字工具调用编辑离散细胞状态的实验设计

本文定义研究方法、比较协议和结论边界，不是运行说明，也不表示下面的实验已经执行。
当前这一路线只有离线功能测试；尚无真实 DeepSeek API 标注、编辑结果或药物预测性能。
数据下载、真实 LEXA 训练及导出的完成状态应以各自 manifest、检查点和核验记录为准，本文不替代这些状态记录。

一、要检验的研究问题

用户希望先用 LEXA 从扰动单细胞表达数据中学到 32 个轴、每轴 16 个状态，再用 DeepSeek 给状态写文字标签。预测时，DeepSeek 阅读药物机制、剂量、处理时间和细胞背景，用普通文本及工具调用提出 code 编辑；冻结的 LEXA 解码器给出修改后的表达变化，供模型检查和修订。

这里不扩展 DeepSeek 的 tokenizer，不新增 special tokens，不训练或微调语言模型。允许训练的是训练集上的 LEXA；一旦导出词典，编码器、codebook、解码器、gene mask、基因顺序、预处理、状态卡和用于比较的 prompt 都固定。每个数据划分要单独训练和导出，不跨划分复用包含测试处理状态的词典。

需要分别检验三个问题：
1. 32×16 的有限表示能否保留本数据中的主要扰动响应？
2. 文字标注及已知机制能否帮助 DeepSeek 选择比简单基线更好的 code 编辑？
3. 在不看真实处理表达的条件下，读解码反馈再修订是否优于一次提案？

这三个问题有不同的失败原因。词典表达能力不足、文字没有增益、反馈没有增益，都应如实报告。功能上符合文字目标的编辑只说明模型内部发生了某种表达变化；真实药物预测还需要与封存的处理数据比较，不能由 DeepSeek 自评代替。

二、主数据与可回答的范围

主试验采用 sciPlex2 小规模药物屏幕（GEO GSM4150377），细胞背景为 A549；药物包括 BMS-345541（BMS）、dexamethasone（Dex）、nutlin-3a（Nutlin）、vorinostat/SAHA。剂量统一明确记录为 µM，处理时间固定为 24 h。该数据适合先验证已见药物的剂量插值，不能用来证明时间外推、跨细胞系泛化或细胞因子响应预测。[1,2]

作者提供 triplicate 标记和培养孔信息。本项目把这些信息用于组划分和匹配，但不把 triplicate 自动称为已经证实独立的生物学重复。需保留原始 well、plate、作者 replicate 标签及其解析方式；若缺少独立培养批次或实验日期证据，统计结论必须保留这一限制。

这是破坏性单细胞测量，不存在同一个细胞的处理前后配对。任务是从匹配的 control 群体预测处理群体的响应，不是给任意 control/treated 细胞强行配对，也不声称恢复单个细胞的真实反事实轨迹。

三、预处理、分组与对照

先根据原始实验注释建立条件网格和样本身份，再依据预先写定的规则做 QC。不能先观察哪些条件效果明显、哪些药物容易预测，再选作测试。

哈希来源 QC：top_to_second_best_ratio > 10、qval < 0.01、hash_umis > 30，三者同时满足。表达 QC：至少 500 UMI、至少 720 个检出基因、线粒体 UMI 占比不高于 10%。这些是本轮预先规定的筛选规则；应输出每步保留/剔除细胞数、各条件样本量和排除原因。

Dex 使用乙醇 vehicle，其余三种使用 DMSO。主评价只用同药物注释、同 plate、同作者 replicate 标记的零剂量群体作为匹配对照；不得把 Dex 的乙醇对照替换成 DMSO，也不因多个条件都写 DMSO 就任意合并。没有严格匹配零剂量群体的 case 应标记不可评估。实验注释无法解析或疑似跨条件混合的记录应单列，不用字符串猜测补齐。

同一物理 well 内所有细胞只能落入一个 train/validation/test 划分。低样本条件默认要求处理与匹配 control 各至少 20 个 QC 合格细胞；不足者标记 small_sample、从主要推断集合排除，并列出数目和条件。样本量阈值不是根据指标调到有利结果的参数。

按全原始基因的每细胞总量归一到 10,000，再取 log1p；随后仅用训练细胞估计基因检出率和方差，选择最多 2,000 个 HVG。训练中检出不足或无方差的基因不纳入。测试细胞使用同一基因列表和顺序，不重新估计 HVG、标准差或 scaffold。

数值数组以唯一 Ensembl ID 为 gene identity，symbol 仅作可读注释。相同 symbol 的不同 Ensembl 条目不能自动合并，也不能在文字证据校验中把 symbol 当成唯一主键。QC 的线粒体识别及所用 symbol 来源应随处理记录保留。

四、数据划分：主协议与次协议

主协议为 seen-drug / unseen-dose：对每种药物，在原实验非零剂量网格中预先确定一个中间剂量，将该剂量的全部培养孔留作测试。中间档按排序后的固定中位索引选择；若档数为偶数，使用实现中固定的上中位索引。选择依据是实验设计网格，而不是 QC 后幸存剂量或处理表达结果。其余剂量按培养孔组划为训练和验证。

因此主协议检验的是：已在训练表达中见过该药其他剂量的 LEXA 词典，结合文字机制能否表达并选择被留出剂量的响应。它不是完全未知药物的预测，也不保证比直接剂量插值更强。

次协议为 leave-one-drug-out：每次完整留出一种药物的所有非零剂量，另外三种药物的处理状态参与训练。依次轮换四种药物；每个 fold 重做训练集 HVG、scaffold、LEXA、状态卡和标注。匹配的零剂量对照可以作为推理时提供的 control 输入，但不能借此把被留出药物的处理表达混入训练或文字卡。

后者只表示“本次实验训练数据未见该药处理表达”。DeepSeek 的预训练可能已包含该药的靶点、公开转录响应乃至本数据的知识，因此不能称为完全无先验的 zero-shot。已知机制是本方法的知识先验；其来源、构造规则及可能记忆公开结果的风险需要在报告中说明。[3,4]

五、LEXA 训练与固定词典

保持每细胞 32 个离散状态、每轴 16 个 code，共 512 个轴内状态词条。code ID 是无序类别；不同轴上的同一个整数也没有共同词义。

pilot 采用仅训练表达构造的 SVD + KMeans 共表达 scaffold，并采用较窄的网络规模。它与原论文依赖细胞类型/供者信息的 scaffold 及网络设置不同，属于面向此任务的原型适配，不是原论文指标复现。SVD、聚类、基因统计和 mask 初始化都不能使用测试处理表达；验证只用于预先约定的训练选择，不能反复查看测试指标再改设置。

训练完成后固定 best checkpoint 和数据划分。导出以下可追踪内容：训练配置与 seed、checkpoint hash、基因 ID/symbol 顺序、训练标准差、训练 code 占用率、训练 code 群体、每个轴/状态/基因的精确解码贡献。通过逐状态贡献求和与实际解码的一致性检查，再允许进入文字标注阶段。

MSE/log1p 模式下，轴内 a→b 的模型表达差是该轴两个贡献向量相减；多轴差异直接相加，不依赖其他轴。这种可审计性是优势，但也限制了轴间非线性交互的表达。若以后使用 NB/count 模式，贡献是 gene-softmax 前的 logits，必须通过最终解码计算表达变化，不能把 logit 差直接称作归一化表达差。

六、DeepSeek 状态文字标注

固定词典后，每轴一次请求，展示该轴全部 16 个状态。每个状态的证据来自“相对同轴 16 状态均值”的贡献：最多六个正向和六个负向基因，保留唯一 gene ID、可读 symbol、原始 delta、训练标准差以及 delta/max(std,0.05) 的数值缩放，并展示训练占用率。

DeepSeek 仅生成 name、summary 和 evidence_genes；不能修改贡献值、占用率、基因身份或状态 ID。evidence_genes 必须来自该状态实际展示的唯一 gene IDs，名称和概述长度受限。不强迫每个状态具有不同功能、完整机制或沿剂量单调排序；弱证据允许标成 unclear。正负方向是相对状态均值，不等于体内激活/抑制的因果结论。

标注按轴验证全部 16 个状态齐全、无重复或越界、证据合法后再原子保存。API 失败或内容不合法时保留已完成轴，停止当前批次，不能补造标签。断点续传必须核对同一 effects hash、显式 model 名与 prompt 版本；单次最多 32 次请求、每轴一次、无隐式重试。原始数字卡始终保留，文字只是可读层，不替换数值证据。

不得把 held-out 处理的差异表达、真实响应通路或目标表达摘要放进标注 prompt。模型机制文本可包含药名、已知靶点、激动/抑制关系、剂量、24 h 和 A549 背景，但应在看测试响应前冻结，不能事后写成贴合答案的文字。

七、纯文字 agent 与数值工具闭环

工具提供三类能力：读取上下文和 control 状态；按轴检查状态卡和相对当前群体的转换；以冻结解码器评价编辑。DeepSeek 以普通文字理解任务，输出结构化的 axis_id、to_code，可选 from_code 和 fraction。来源/目标 ID、取值范围、重复轴及最多三轴的限制由本地工具硬校验。[6]

from_code 指定只修改当前处于该来源状态的细胞；省略表示所有来源状态均可被选择。fraction∈[0,1] 指定其中被编辑的群体比例，省略为 1；按固定 seed 和稳定细胞顺序选取。每个 proposal 都从原始 control 开始，不把前一轮的结果作为新的、逐步累积的输入。

fraction 可以让连续剂量条件对应不同群体占用率，但它仍是 agent 的编辑参数，不是从实验学得的药物效价或校准 dose-response。一次固定替换也不能表达全部细胞背景依赖；未经支持的状态组合应报告分布支持未知或距训练组合的距离，而不是据此认定细胞状态真实可达。

反馈只包括模型实际算出的数值变化、改变细胞数、相关基因与预先指定文字目标的方向一致性、训练支持信息和技术约束。绝不返回 held-out 真实表达或其评分。agent 可据此修订，但语言上更符合预期的输出仍可能与真实药物方向相反。

最终结果只绑定最近一次实际成功评价的 proposal。提前结束、工具调用失败、预算耗尽和未评价的提案必须明确区分；不能把最后一句自由文本中的新提案冒充已经过解码。记录每次 inspect、proposal、evaluation 和最终选择，便于审计。

八、预先固定的比较与消融

1. no-edit：control codes 保持不变，预测 delta 为零。
2. train-mean：只用训练处理群体估计的平均响应，不使用测试处理。须预先固定按 well/condition 加权的规则，避免细胞多的条件自动占据全部权重。
3. nearest-dose：主协议中使用同药物训练剂量的最近邻响应，距离规则预先固定，例如正剂量的 log10 距离。没有该药训练剂量时标记不可用，不能在 leave-one-drug-out 中偷偷访问被留出药物。
4. one-shot：读取同样的状态卡后只评价一个 proposal；不通过真实目标决定是否重做。
5. feedback：最多评价三个 proposal，允许读取前次冻结解码结果再修订，最终选取规则预先固定；不得在三个 proposal 中用真实测试 score 选最好者。
6. no-labels：不提供 DeepSeek 生成的 name/summary，保留完全相同的基因、数字状态卡和工具预算，检验文字标签是否超出原始基因证据带来增益。
7. shuffled-labels：按固定 seed 在同轴状态间打乱 name/summary，保留状态 ID、原始数字卡和有效基因证据映射；用于检查 agent 是否只是依赖流畅名称或标签装饰。打乱方式不能改变原始表达数据。

one-shot 与 feedback 使用同一个冻结词典、同一套标注、同样的机制描述和输入 control；no-labels、shuffled-labels 也保持其余可见信息一致。报告实际 API 请求数、解码评价次数、预算失败率，避免把额外调用预算的优势全部解释成文字方法优势。

默认四个 case 仅用于 screening 和端到端流程检查，按预先固定的规则从合格条件选择、尽量覆盖四种药物；不能看指标后换 case。正式结论需另外运行全部合格 held-out cases，并报告总数、有效数、小样本/缺对照排除数。screening 的四个结果不能代替完整评测，也不能作为调参集反复选择有利 prompt 后继续充当测试集。

九、预测对象与评价指标

主要对象是条件/培养孔群体的表达变化：

  Δtrue(g) = mean[log1p(CP10K)treated(g)] - mean[log1p(CP10K)matched-control(g)]

  Δpred(g) = mean[D(edited-control-codes)(g)] - mean[D(original-control-codes)(g)]

D 是同一个冻结解码器。第二式比较修改前后解码结果，可减少共同 control 重构偏差对差异的干扰，但并不保证扰动差异被正确表示。所有方法比较时使用相同基因列表、单位和匹配对照定义。

主要报告 ΔMSE/MAE、Δ向量 Pearson/Spearman、方向一致性以及预先指定基因/通路的响应。对常量预测或近零真实响应导致的相关性未定义，应明确写 NA，不用随意的零或一替代。弱响应条件同时报告真实效应强度和误差，不能因为相关性难看就隐去。

全基因绝对表达 Pearson 很容易主要反映细胞的共同背景，不能作为主要证据。还需查看相对 train-mean、nearest-dose 的增益，以及模型能否区分不同药物的响应。Systema 对系统性变化和指标偏差的讨论提示，即使用 control 为参考的 delta 指标，也未必完全隔离扰动特异性；本试验借鉴这一评价动机，不声称已经复现完整 Systema 框架。[5]

真实测试处理表达、测试差异基因列表和任何 target 派生的响应摘要只能由独立 score 阶段读取。score 阶段可以将预先定义的 DE 方向/排序作为补充评价，但这些信息不得再反馈给 agent、用于生成机制描述、挑选 proposal 或修改 prompt。目标文件不是 agent workspace 的输入。

对原始表达、baseline、效应文件、labels 和 proposals 记录 hash 与 split provenance。数据隔离首先是可核查的程序接口和产物约定；若没有独立进程/目录权限等额外隔离措施，不应声称已经构成抵抗恶意访问的安全沙箱。

十、表示上限诊断与失败分析

可在封存预测后，用冻结编码器对真实处理表达做 E(target)，检查 D(E(target)) 是否保留其关键响应。这是 representation oracle：测试目标只用于诊断现有词典能否表示答案，不用于训练编辑器、造卡、选 code 或决定最终预测。

若连该诊断都无法保留真实响应，应优先讨论 HVG 遗漏、32×16 粒度、网络容量、离散化损失或固定加法结构。若 oracle 较好而文字编辑较差，问题可能在语义映射、剂量强度、组合支持、来源状态选择或 agent 的比较策略。oracle 不能被列作可部署预测结果，也不能用其 code 充当“文字方法”的提案。

本路线不保证正结果。no-edit、train-mean 或 nearest-dose 胜出，或标签打乱后无明显退化，都可能是有价值的否定结论。不得只报告最好的药物/seed，也不得把不显著结果重新包装成已经证实的机制可解释性。

十一、随机性、统计单位与扩展顺序

区分 LEXA 初始化 seed、scaffold seed、细胞/群体抽样 seed、fraction 的固定选择 seed，以及 DeepSeek 请求本身的随机性。同一方法至少进行预先约定的多次独立重复；保留各次完整提案和失败记录，不能重跑直到取得好结果。

统计比较以 well 或 condition 为单位，在同一 case 上做方法间配对比较。多个细胞来自同一培养孔，不能把它们当作数千个独立实验来制造极小 P 值；多个 agent seed 也不是新增生物学重复。四种药物和作者 triplicate 的规模有限，优先报告逐条件结果、效应大小及适当的区间，明确独立重复证据不足。若采用层级 bootstrap，按 drug/condition/well 的结构重抽样，而不是只重抽细胞。

扩展顺序：先完成单一 A549、固定 24 h 的剂量任务及全部对照；再讨论完整留药；取得可信证据后，才增加其他细胞背景、独立供者、多时间点和细胞因子。时间、剂量及机制文本可以是通用接口，但当前数据不能支撑对这些维度全部泛化的结论。药物效价、延迟、反馈和毒性需要真实数据校准，不会因文字标签变得可解释而自动得到解决。
