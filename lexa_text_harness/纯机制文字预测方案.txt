纯机制文字预测：DeepSeek 能否依据药物机制与 code 语义推断扰动
日期：2026-10-27，Asia/Shanghai
状态：设计完成，尚未实现或运行。本方案取代“训练响应检索＋语言修正”作为用户当前主线；旧版结果原样保留。

1. 研究问题与输入边界

目标是检验 DeepSeek 能否利用药物机制和冻结 code 的文字含义，推断真实扰动的状态变化与基因变化。无需训练新增token或微调LLM，矩阵与解码计算保留在本地。

可见信息：
- 药物作用靶点、作用方式、一般调控关系、适用条件及来源；给定剂量/时间/细胞背景。
- 当前匹配对照细胞的状态占用、表达背景。
- 冻结轴和state卡：范围、正负基因贡献、轴内参考、状态间差异、训练支持度。
- 无处理条件标签的训练状态支持度，可作为保守的分布诊断。

不可见信息：
- 任意训练药物的配对表达响应、条件分组占用变化、剂量响应轨迹或据此生成的候选。
- 目标条件处理后的表达、DEG列表、真实code占用或答案拟合结果。
- 从已揭盲数据总结出的“该药应该改变哪些轴/多少比例”。

现有v3的nearest/interpolate/lower/upper/half/onehalf候选、reference_observed_delta和training_library必须整体移出预测路径；仅隐藏其文字来源仍然携带响应信息。新候选只能由control p0、冻结state效应、DeepSeek提出的状态偏好构建。

机制资料应预先整理并固定版本；一般靶点和调控关系可以使用，但不能把目标数据集或相同实验条件的转录响应表改写成“机制”。药物抑制某蛋白，不自动意味着对应mRNA下降。LLM预训练可能包含已知药物知识，实验检验其有效使用知识，不能仅凭结果断言产生了全新生物学推理。

2. 流程：先冻结机制假设，再选状态，再解码核查

阶段A：机制假设（一次调用）
输入药物机制、给定条件和对照背景，暂不提供具体code编号。
输出明确、简短、可核查的假设：预期增强/减弱的程序或有依据的基因方向、直接机制/次级推断分类、依赖条件、引用来源、未知部分。
这是模型预测的中间假设，不是真实答案；后续反馈不能把它当已证明药效。
不得把置信程度当表达幅度，也不要求所有无关活动必须不变。药物可能产生广泛次级效应。

阶段B：32轴状态选择（4批×8轴）
共享阶段A假设和全部32张简短轴卡；每批展开8轴、每轴16states。
保留正负贡献和容易混淆状态的区别：同名state可能有不同的关键基因方向。显示相对当前对照的真实模型效应，而不只给静态功能名称。
每轴输出：
  axis_id
  decision: shift | keep | unknown
  preferred_states: state_id与少量归一化目标权重
  disfavored_states
  evidence_refs: 机制假设ID与state证据ID
  expected_direction: 简短表达变化假设
  limitations
所有32轴均可修改，不设3轴硬上限；unknown与有证据的keep分开记录。模型需解释状态选择依据，不要求输出内部思维链。

阶段C：本地生成占用方案并精确解码
若轴选择shift，先将DeepSeek选中的目标states与相对权重归一化为r_a。
用 q_a=(1-alpha)*p0_a+alpha*r_a 得到群体占用。r_a可包含当前control占用为0、但词典中有支持的状态，允许新状态出现。keep/unknown在数值上保留p0，但报告语义不同。
alpha是编辑强度，不是模型置信度或已校准剂量反应。首版可预先固定0.10/0.30/0.60三个共同强度，0.30作为主方案，另外两档只作敏感性分析；这些数值是工程设置而非已验证最优。禁止对每孔查看真值后选最优档作为预测成绩。
只用本地decoder计算Δ=sum_as(q-p0)*u；不向LLM提供真实响应误差，也不生成训练表达参考目标。这样仍由DeepSeek决定状态方向，程序只完成概率合法性与算术。

阶段D：一次有明确检查项目的联合复核
给DeepSeek已经冻结的机制假设、局部选择、精确解码上/下调基因与功能评分变化，检查：
- 选中的state是否实现其先前声称的方向；
- 多个轴是否抵消某项关键变化；
- 不同提案是否对同一基因提出相反要求；
- 是否存在支持不足、错误引用、无效来源状态等问题。
允许保留或修订，不强迫制造修改。若目标本身有冲突，明确列为不确定，不能靠反复改写目标让任何结果都显得合理。
一次联合复核后的输出为主版本，同时保存之前局部版本。两者调用预算不同，比较只解释整套流程增量，不能单独归因于反馈机制。
整体每case名义6次调用（1机制+4局部+1联合），失败修复另有固定上限与完整留痕；当前只是计划预算。

3. 方向与幅度同时评价，避免一个RMSE掩盖原因

方向侧：真实基因Δ的Pearson/cosine、正负方向、代码占用变化的有符号排序；全部32轴、2000建模基因统一评价，同时报告输出覆盖率/unknown比例，不能只挑模型有把握的少数状态。
幅度侧：未经答案缩放的ΔRMSE、预测/真实响应L2比、每轴TV；三个预设强度全部报告，主方案预先指定。
若方向正确而幅度不准，说明机制—state映射可能有效但定量预测不足；若方向也不对，应检查机制理解、state语义或编码表示，不能靠按答案放大修复。
真实处理code与表达只在预测全量封存后用于评分。群体占用不是单细胞前后配对。阈值若依据对照重采样确定，应提前固定，只描述采样稳定性，不替代生物重复。

4. 最小归因实验

采用相同调用/候选/幅度/数值评价预算的2×2：
A. 药物机制可见 + code语义可见。
B. 药物机制隐藏 + code语义可见。
C. 药物机制可见 + code语义隐藏。
D. 两者隐藏。
隐藏机制时药名也匿名；隐藏code语义时，卡片和所有decoder反馈中的基因/功能身份都匿名，保留同样的数值及真实解码器，防止从侧路恢复语义。整个code语义消融与仅去掉LLM生成的name/summary不同；后者若仍保留基因身份，只能检验额外文字摘要的价值。
另设no-edit和简单有符号关键词/基因集匹配选码基线，使用相同可见机制资料；不得由规则基线作者把已知真实响应写入签名。
只有完整版超过去机制、去code语义及简单匹配，才能支持模型有效结合了两种信息。状态ID一致重编号可作额外稳健性检查，不把编号当生物语义。

5. 数据与结论范围

当前4药/16ready5µM已被查看，只能开发。正式测试需新未触碰条件或数据集，并在划分后重新选择特征、训练codec、生成标注；测试处理细胞不能进入这些环节。
现有codec可以先冻结用于开发，已有axis/state文字卡仅由训练基因效应生成，可复用，但需审计没有药物条件响应混入。
第一次纯机制版优先检验状态方向，同时保留固定幅度的完整表达预测。不能把方向指标好等同于已解决剂量、时间与细胞群响应比例的定量预测。
本轮未运行新的DeepSeek调用、未修改预测实现、未重训；旧检索版不再被当作此研究问题的主实验。
